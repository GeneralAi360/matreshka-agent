Используй $$matreshka-agent:designing-product-experience для этой задачи.

Запрос: $ARGUMENTS

Сначала изучи существующий интерфейс, design tokens, компоненты и root `DESIGN.md`, если он есть. Для UI-проекта без `DESIGN.md` подготовь один канонический root-контракт. Если пользователь не понимает, какой дизайн хочет, предпочти несколько действительно разных интерактивных направлений вместо длинного опроса о цветах и радиусах.

Используй обязательное дизайн-ядро Matreshka: Purpose, Agency, Responsibility, Familiarity, Flexibility, Simplicity, Craft, Delight, wayfinding, feedback, hierarchy, typography, accessibility и осмысленную motion-систему. Не имитируй визуальный стиль Apple автоматически — эти принципы описывают качество опыта, а не тему оформления.

Не устанавливай библиотеки, не запускай браузер/сервер, не меняй production-код, Git или remote systems без соответствующего разрешения.
